# VYNTRAX UI

Official UI Component Library and Design System for **VYNTRAX Intelligent Software**.

This repository contains reusable user interface components, design tokens and front-end standards shared across all VYNTRAX projects.

---

# Purpose

The goal of this repository is to provide a consistent, accessible and reusable Design System that accelerates development while maintaining a unified visual identity.

Every VYNTRAX application should use components from this library whenever possible.
